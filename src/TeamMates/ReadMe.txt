Welcome to Erowind

It began as a fun personal project to create characters for roleplyaying while I learn React more in depth but quickly became a large scale immersive solo quest.

The technology used is simply React, Javascript, JSX, Node, CSS/HTML. 

Notable mechanics include an intricate battle system with many variables, and scalable for larger fighter/devolpments.
An Ai hero image generator depending upon the characteristics and attributes the player selects.
A trial and training system that inclucdes some carefully coded puzzles.
