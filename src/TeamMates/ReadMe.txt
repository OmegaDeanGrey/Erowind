Welcome to Erowind

It began as a fun personal project to create characters for roleplyaying while I learned React more in depth but quickly became a large scale immersive solo quest.

Frontend

React
JavaScript (ES6+)
JSX
CSS3
HTML5

Backend (In Progress)
Node.js
Planned: ASP.NET Core + SQL Server (Docker) for persistent world state

Notable mechanics include an intricate battle system with many variables, and scalable for larger fighter/devolpments.
An Ai hero image generator which depends upon the characteristics and attributes the player selects.
A trial and training system that includes some carefully coded puzzles.

Locate this project on github here: https://github.com/OmegaDeanGrey/Erowind
